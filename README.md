# Food Recommendation RAG Chatbot


An intelligent food recommendation system built using Python, semantic similarity search, and Retrieval-Augmented Generation (RAG).

## 🚀 Features
- **Interactive Search Chatbot (`interactive_search.py`)**: CLI-based food search tool with session tracking and query history.
- **Advanced Multi-Criteria Search (`advanced_search.py`)**: Filtered search implementations for precise culinary matching.
- **Calorie Budget Checker (`calorie_checker.py`)**: Interactive tool to find meals fitting specific calorie limits.
- **RAG Natural Language Assistant (`enhanced_rag_chatbot.py`)**: Conversational AI assistant providing recipe insights and context.
- **Result Limiter Evaluation (`result_limiter.py`)**: Quality and score analysis across varying result counts.

## 📂 Dataset
- Built on `FoodDataSet.json` containing diverse food items, descriptions, calories, and cuisine categories.
